# Actividad Sumativa: Optimizando un Sitio Web con HTML, CSS y Diseño Responsivo

# Descripción de la actividad Sumativa

En esta tercera semana realizarás la optimización de un sitio web básico de ecommerce de la tienda de video Juegos en HTML y CSS. La actividad se centra en mejorar la apariencia visual del sitio utilizando el modelo de cajas, colores, tipografías y selectores CSS. Además, se aplicarán técnicas de diseño responsivo para asegurar que el sitio se visualice correctamente en dispositivos de diferentes tamaños. En particular, se emplearán Flexbox y CSS Grid para organizar la disposición de los elementos de manera adaptable. Esta actividad te permitirá aplicar los conceptos fundamentales de diseño web responsivo y buenas prácticas de desarrollo.

# Instrucciones Específicas

- Optimiza el sitio web aplicando estilos CSS para definir la estructura y apariencia de los elementos.
- Utiliza el modelo de cajas para ajustar el espacio alrededor de los elementos, incluyendo propiedades como márgenes, rellenos y bordes.
- Elige colores de fondo, texto y bordes adecuados, así como una tipografía que mejore la legibilidad y estética general del sitio.
- Ajusta el diseño visual para que sea responsivo, utilizando Flexbox y CSS Grid, garantizando que el contenido se visualice correctamente en diferentes tamaños de pantalla, como dispositivos móviles, tabletas y escritorios.
- Asegúrate de verificar y probar el sitio en distintos dispositivos y resoluciones utilizando herramientas de inspección de navegador para validar la estructura responsiva y su presentación visual.

## Instrucciones paso a paso

- Crea una Hoja de Estilos CSS Externa
- Crea un archivo CSS en tu entorno de desarrollo y asegúrate de enlazarlo correctamente con el archivo HTML del sitio.
- Define la Estructura Visual con el Modelo de Cajas
- Aplica propiedades de modelo de cajas como padding, margin, border y box-sizing para definir el espacio y la disposición de los elementos en la página.
- Asegúrate de que cada sección esté claramente delimitada y organizada.
- Elige Colores y Tipografía
- Define colores para el fondo, el texto y los bordes de los elementos para mejorar la estética y la legibilidad.
- Selecciona una tipografía adecuada y ajusta el tamaño del texto para cada sección del sitio.
- Diseño Responsivo con Flexbox y CSS Grid
- Utiliza Flexbox para organizar elementos horizontales como la barra de navegación y el pie de página.
- Emplea CSS Grid para organizar las secciones principales del sitio y los elementos de contenido, asegurando que se adapten a distintos tamaños de pantalla.

---

- Añade media queries para ajustar la visualización en dispositivos móviles, tabletas y pantallas de escritorio.
- Aplica Selectores y Estilización Avanzada
- Emplea selectores de clase, ID y selectores avanzados como nth-child o :hover para personalizar y mejorar la presentación visual.
- Asegúrate de que la página mantenga una apariencia uniforme y atractiva.
- Prueba y Verifica la Adaptabilidad del Diseño
- Usa herramientas como DevTools para verificar que el diseño sea responsivo en diferentes resoluciones y dispositivos.
- Realiza ajustes según sea necesario para asegurar que el sitio funcione correctamente en todas las visualizaciones.
